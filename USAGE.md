# 🧬 Using the FAIR_Implementation_ABM Repository

This guide explains how to set up the model, build the documentation, and view it locally in your browser.

---

## 📦 Prerequisites

Make sure you have the following installed:

- [Julia](https://julialang.org/downloads/) (version ≥ 1.8 recommended)
- `git` (if you're cloning the repository)
- A text editor (e.g., VS Code, Atom, Sublime Text)
