# Manuscript Data

This folder contains the ensemble simulation data used to generate
the manuscript figures. Each subfolder corresponds to one figure.

---

## Figure_3/

Four CSV files aggregated across five independent simulation runs using
the default parameter set (no crowding; no oligomer clearance).
Each file has one `Timesteps` column followed by one column per run.

| File | Contents |
|---|---|
| `Appending_AggregateProne_Count.csv` | AggregateProne monomer count at each timestep |
| `Appending_Native_Count.csv` | Native monomer count at each timestep |
| `Appending_Oligomer_Count.csv` | Oligomer count at each timestep |
| `Appending_Aggregate_Count.csv` | Aggregate count at each timestep |

**Generated by:** `Run_All_Analysis_Scripts.jl` →
`Append_AggregateProne_and_Native.jl` and `Append_Aggregate_and_Oligomer.jl`

**Plotted by:**
- `Analysis/Plot_Fig_3_publication.py` — publication figures (EPS, TIFF, PDF)
- `Analysis/Plot_Fig_3.jl` — exploratory (PNG)

## Figure_4/

Two CSV files aggregated across five independent simulation runs,
comparing baseline (no clearance) against oligomer clearance enabled
(p = 0.05). All other parameters are identical to Figure 3.

| File | Contents |
|---|---|
| `No_Oligomer_Clearance/Appending_Aggregate_Count_No_Oligomer_Clearance.csv` | Aggregate count, no clearance |
| `Oligomer_Clearance/Appending_Aggregate_Count_Oligomer_Clearance.csv` | Aggregate count, clearance enabled |

**Generated by:** `Run_All_Analysis_Scripts.jl` →
`Append_Aggregate_and_Oligomer.jl`

**Plotted by:**
- `Analysis/Plot_Fig_4_publication.py` — publication figures (EPS, TIFF, PDF)
- `Analysis/Plot_Fig_4.jl` — exploratory (PNG)

## Figure_5/

`Simulation_Runtimes_Minutes.csv` — wall-clock runtimes (minutes) for 300
independent benchmark simulations run on the Notre Dame Center for
Research Computing (1,000 monomers; 5,000 timesteps; 30 × 30 × 30 FCC
lattice; 15 parallel jobs).

**Plotted by:** `Analysis/Plot_Fig_5_publication.py`
